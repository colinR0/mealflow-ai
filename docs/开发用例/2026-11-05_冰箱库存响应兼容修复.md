# 冰箱库存响应兼容修复记录

日期：2026-11-05

## 问题

用户截图显示库存页报错 `Cannot read properties of undefined (reading 'length')`。库存列表页将响应直接视为分页对象并读取 `page.items.length`，但仍运行旧后端时接口可能返回数组。

## 修改

- 库存列表兼容分页 envelope 和旧版数组响应。
- 旧数组响应下展示返回记录并关闭“加载更多”，避免旧接口忽略 offset 后重复追加同一页。
- 对其他意外响应格式显示明确的后端接口格式错误，而不是暴露 JavaScript 属性异常。
- 为旧数组兼容与无效响应添加前端页面方法回归测试。

## 验证

- 待运行 `node --test tests/inventory-retry.test.mjs` 与 `npm run typecheck`。

## 限制

- 旧数组响应没有 total/has_more，客户端无法判断是否还有后续记录；完整分页需后端返回当前分页 envelope。
