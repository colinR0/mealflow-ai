# 冰箱库存模块开发记录

日期：2026-11-05

## 本次完成

- 移动端库存读写统一使用 `inventory_lots`，沿用 v2 登录身份和家庭授权检查。
- 增加库存生命周期 `active`、`consumed`、`removed` 和备注字段的 Alembic 迁移；生命周期操作写入库存变更流水。
- 库存 API 支持分页、稳定排序、搜索、数量状态及生命周期状态筛选，并提供完整库存统计。
- 接通库存列表、新增、编辑、标记用完和移除交互；写操作带版本检查，只有 `active` 记录可转换为终态。
- 保持数量未知语义：未知数量的数量和单位为空；已知数量需满足数据库精度约束。数量越界或精度损失的输入由 API 返回 422。
- 为名称长度超过 ingredient key 列宽的情况生成稳定 key，避免合法名称导致数据库错误。
- 操作失败后刷新当前查询以获取最新记录和版本；分页读取失败则重试原页。
- 保留用户原有的冰箱首页及设备、菜谱页面改动。
