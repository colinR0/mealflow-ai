# 菜谱 JSON 质量评估脚本

日期：2026-11-07 11:25（Asia/Shanghai）

## 范围与文件

- 新增 `scripts/evaluate_recipes.py`：只读评估菜谱 JSON，输出逐条问题、能力候选及可复现人工抽检清单。
- 新增 `docs/菜谱数据质量评估流程.md`：记录运行方式、人工抽检、发布门禁与局限。
- 本记录为本次开发新增；未修改既有菜谱、数据库或索引。

## 交付行为

默认评估 32 条种子菜谱与 937 条 V1 合并菜谱。支持指定其他 JSON 文件、导出汇总 JSON、逐条 JSONL 和人工抽检 CSV。自动检查不能代替来源许可、内容准确性及过敏安全审核。

## 验证结果

- `python -m py_compile scripts/evaluate_recipes.py`：通过。
- `python scripts/evaluate_recipes.py`：通过；共 969 条，567 条缺步骤，937 条结构化用量未知，9 组同名候选；32 条具备可计算用量的字段候选。
- `--report-dir` 导出验证：`summary.json`、`items.jsonl`、`manual_review.csv` 分别含 969 条汇总范围、969 条逐条结果、30 条抽检样本。
- 边界输入验证：无步骤、无效来源 URL、未知用量和非有限数值按预期识别。
- 当前系统 Python 环境未安装 `ruff`，因此未运行 Ruff；仓库指定的 Conda 解释器路径在此执行环境中不存在。

## 已知缺口

- 当前结果只覆盖 JSON 文件，不代表 PostgreSQL 运行库记录数或正式发布状态。
- 合并文件的来源许可和内容真实性需人工核对；脚本不自动判定合规。
- 未评估真实检索召回、回答质量及性能；这些属于建索引后的独立阶段。
